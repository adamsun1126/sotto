# sotto

Локальная диктовка по принципу «нажми и говори» для macOS, вдохновлённая Wispr Flow.

Удерживайте **правую Option**, говорите, отпустите. Речь транскрибируется, очищается (убираются слова-паразиты, заикания и самоисправления, расставляются знаки препинания) и вставляется в позицию курсора.

Всё работает на вашем Mac. Аудио хранится только в памяти. Ничего не логируется и не сохраняется.

> Сейчас диктовка поддерживает **английский** и **традиционный китайский** (в том числе вперемешку).

- Распознавание речи: [mlx-whisper](https://github.com/ml-explore/mlx-examples) (`whisper-large-v3-turbo`, Apple Silicon)
- Очистка: [Ollama](https://ollama.com) с моделью `qwen2.5:7b`
- Китайский вывод приводится к традиционному написанию через OpenCC

## Требования
macOS на Apple Silicon.

## Установка (один раз)
```bash
brew install uv ollama
ollama pull qwen2.5:7b
```
Модель Whisper (~1,6 ГБ) скачивается автоматически при первом запуске.

## Запуск
```bash
./run.sh
```
При первом запуске macOS запросит два разрешения: **Микрофон** и **Универсальный доступ** (Системные настройки > Конфиденциальность и безопасность > Универсальный доступ: включите приложение терминала, из которого запускаете). Выдайте оба и запустите снова.

Оставьте запущенным. В любом приложении удерживайте правую Option и говорите.

## Настройки
Переменные окружения:

| Переменная | По умолчанию | Значение |
|---|---|---|
| `FLOW_HOTKEY` | `right_option` | Удерживаемая клавиша (`right_cmd`, `right_ctrl`, `caps_lock`, `f13`, ...) |
| `FLOW_LLM` | `qwen2.5:7b` | Модель Ollama для очистки (`qwen2.5:3b` меньше, но хуже справляется с самоисправлениями) |
| `FLOW_WHISPER` | `mlx-community/whisper-large-v3-turbo` | Модель Whisper (`mlx-community/whisper-small-mlx` быстрее) |
| `FLOW_LANG` | auto | Принудительно `zh` или `en`. Автоопределение справляется со смесью китайского и английского |
| `FLOW_CLEANUP` | `1` | `0` вставляет сырую транскрипцию без очистки LLM |

Пример: `FLOW_HOTKEY=f13 FLOW_LLM=qwen2.5:3b ./run.sh`

## Конфиденциальность
Никаких сетевых запросов, кроме однократной загрузки моделей. Файлы не записываются. Истории нет. Единственный след сказанного — текст, вставленный в приложение, и системный буфер обмена.
